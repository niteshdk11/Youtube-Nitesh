# 🧭 Universal Lead Scraper

This repo contains simple **lead-scraping scripts** that you can paste directly into your **browser console** to collect **real business leads** from different websites like **Yellow Pages**, **Meta Ad Library**, and more (coming soon).

Each script automatically downloads the data in a **CSV file** — no paid tools, no setup, just your browser.

---

## ⚙️ How to Use

1. Open the target website (e.g., Yellow Pages or Meta Ad Library).  
2. Open **Developer Tools → Console** (`Ctrl + Shift + I` on Windows / `Cmd + Option + I` on Mac).  
3. Copy the script content from this repo.  
4. Paste it into the console and press **Enter**.  
5. Wait a few seconds — the leads will automatically download as a `.csv` file. ✅  

---

## 📝 Note

- Websites update their **UI / HTML structure** from time to time.  
  If the script stops working, you might need to update the **CSS selectors** (like class names or tags).  
- Always make sure the entire page has loaded before running the script.  
- Use these scripts **responsibly** — for learning, research, and legitimate outreach only.  
  **Don’t spam or misuse** the collected data.

## 📂 Available Scripts
